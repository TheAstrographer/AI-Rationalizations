## 1. The Markovian Trajectory of Autoregressive Generation
An autoregressive language model generates an upcoming sequence by conditioning exclusively on the preceding sequence string. Let the context window at sequence step $t$ be represented as a concatenated sequence of tokens: [1] 
$$W_t = (x_1, x_2, \dots, x_t)$$ 
The probability of generating the next token $x_{t+1}$ is formalized as:
$$P(x_{t+1} \mid W_t) = \prod_{i=1}^{t} P(x_i \mid x_1, \dots, x_{i-1})$$ 
## The Compounding Error Cascade
If an ungrounded or hallucinated token $x_H$ is injected into the context window at step $k$ (where $k \le t$), the model no longer computes probabilities relative to the objective ground-truth world $\mathcal{W}_{\text{actual}}$. Instead, it shifts its entire computational matrix to optimize compatibility with a fictional state $\mathcal{W}_{\text{phantom}}$:
$$P(x_{t+1} \mid x_1, \dots, x_H, \dots, x_t) \propto \text{Similarity}(x_{t+1}, x_H)$$ 
Because each successive token relies directly on the historical integrity of its ancestors, the probability of recovering a grounded baseline decreases exponentially as the ungrounded chain lengthens. This mathematical trap is known as the Autoregressive Error Accumulation model. [2]

## 2. Attention Weight Concentration and Path Inflation
The mechanism driving this path dependency is the Scaled Dot-Product Attention engine. For a query matrix $Q$, key matrix $K$, and value matrix $V$, attention weights are determined by: [3] 
$$\text{Attention}(Q, K, V) = \smash{\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V}$$

* The Extremity Biases: Models retain sharp recall for tokens located at the absolute beginning or the absolute end of the context window. [4]

This structural collapse means that simply expanding a context window does not fix hallucinations. Instead, longer windows provide a vast, unmonitored space for information to dissolve, increasing the mathematical necessity for human intervention. [4, 5]
